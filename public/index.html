Automatico sul Wi-Fi (iPhone)

Comandi → Automazione → Wi-Fi → quando ti colleghi alla rete Bocconi → "Esegui immediatamente":
  1. Ottieni indirizzo IP attuale, tipo Esterno
  2. Ottieni dettagli rete → Nome rete
  3. Ottieni contenuti dell'URL: POST, JSON con ip e ssid
  4. Mostra notifica con il campo msg
